# 採用ルール：上級

## 資料

- [商品紹介](https://store.universal-music.co.jp/products/uizz4391)：商品版のルール区分、3段までの積み重ね、自由配置。
- [公式Q&A](https://www.universal-music.co.jp/other/hunter-gungi__qa/)：最上段だけの移動、帥の上へのツケ禁止、捕獲・新・寝返りの補足と訂正。弓の飛び越えは掲載されている7枚の図も参照。
- 商品付属の「駒の動き早見表」：[購入者が掲載した写真](https://www.ptt.cc/bbs/Hunter/M.1665549400.A.140.html)、[参照画像](https://i.imgur.com/8bldOrr.jpg)。14種類の枚数と各段の着地点を確認。画像自体はアプリへ転載しない。
- [軍儀Webのルール解説](https://gungi.2410.dev/rules.html)：自由配置の終了手順、高さの制限、新の範囲、特殊操作を照合。コード・画像は利用しない。

作中のすべての規則が定義されているものとして扱わず、商品版の上級を基準とする。

## 配置と盤面

9×9盤、各25枚。各マスに駒を下から順に最大3枚置く。手番と駒の向きは先手・後手で180度反転する。
先手から交互に帥を最初に置き、自陣の3行へ自由に配置する。帥の上には配置しない。
先手の「済み」後は後手だけが配置を続け、後手の「済み」で配置を終了する。全手駒を使った場合も済み扱いとする。
対局は初期配置と同じ先手から始める。

## 移動と操作

- 動かすのは最上段の1枚。移動範囲は移動前の段数で決まり、下段は元のマスに残る。
- 移動先の高さが移動元を超える場合、捕獲・ツケはできない。
- 帥の上へツケることはできない。帥自身は他の駒へツケられる。
- 捕獲は移動先の最上段が相手の場合に選ぶ。そのマスの相手駒すべてを除外し、味方駒は残して、その上に移動駒を置く。
- 通常のツケは相手駒も下段に残す。相手が最上段の3段塔へ3段からツケる場合は、最上段だけを除外して重ねる。
- 手駒の新は、最上段が自駒の最前線と同じ行または手前。埋もれた自駒は前線の計算に含めない。空きマスまたは3段未満の自駒の上に置く。謀だけは相手の上にも新でツケられる。
- 寝返りは謀のツケに付随する任意の操作。残る相手駒すべてと同じ種類・枚数の手駒が必要。手駒を使って同じ段に入れ替え、相手駒は除外する。必要な手駒がない場合、通常のツケは選べる。

移動・取る・ツケ・新はいずれも一手で手番が交代する。寝返りもツケと合わせて一手とする。

## 駒の動き

以下の `t` は1〜3の段数。距離の範囲は途中の着地点も含む。無制限の方向は段数で変化しない。

| 駒 | 枚数 | 動き |
| --- | --- | --- |
| 帥 | 1 | 周囲8方向へ1〜tマス |
| 大 | 1 | 縦横無制限、斜め1〜tマス |
| 中 | 1 | 斜め無制限、縦横1〜tマス |
| 小 | 2 | 前・前斜め・左右・後へ1〜tマス |
| 侍 | 2 | 前・前斜め・後へ1〜tマス |
| 槍 | 3 | 前へ1〜t+1マス、前斜め・後へ1〜tマス |
| 馬 | 2 | 前後へ1〜t+1マス、左右へ1〜tマス |
| 忍 | 2 | 斜めへ1〜t+1マス |
| 砦 | 2 | 前・左右・後斜めへ1〜tマス |
| 兵 | 4 | 前後へ1〜tマス |
| 砲 | 1 | 前へ3〜t+2マスを飛び越え、左右・後へ1〜tマス |
| 弓 | 2 | 前へ2〜t+1マス。各距離nで左右のずれは0または±(n−1)。後へ1〜tマス |
| 筒 | 1 | 前へ2〜t+1マスを飛び越え、後斜めへ1〜tマス |
| 謀 | 1 | 前斜め・後へ1〜tマス |

通常移動では途中に駒があると進めない。砲・筒・弓の前方移動では同じ高さ以下を飛び越えられ、高い駒が途中にあると進めない。
弓の左右への飛び越えは、前へ1マス進んでから斜めに進む経路と、斜めに進んでから最後に前へ進む経路の通過マスを確認する。直前の中央の高い駒は前方3方向を遮断し、直前の左右の高い駒はその側を遮断する。

## アプリでの扱いと省略

- 帥の捕獲または投了で決着。王手・詰み・千日手は自動判定しない。
- 先手後手の決め方、時間制限は対局者に任せる。
- 待ったは直前の配置・済み宣言・一手・投了を取り消す。捕獲・寝返り・段の順序・手番・決着も復元する。
- 誤操作を防ぐため、済み・待った・リセット・投了は確認ダイアログを使う。
- 通信・AI・保存は実装しない。再読み込みで対局を初期化する。
