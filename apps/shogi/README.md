# 将棋

通常の将棋と変則将棋の駒を、共通の移動規則で扱う静的ブラウザアプリ。
同じ画面で2人が交互に操作する。画面上部で通常将棋（9×9）・中将棋（12×12）・大将棋（15×15）・大局将棋（36×36）を切り替えられる。

- 通常将棋は持ち駒・駒打ちに対応。捕獲した成り駒は不成に戻して持ち駒にする。王は持ち駒にしない。
- 二歩と行き所のない駒は、一手の完了後に反則負けと判定する。候補表示からは除外しない。
- 王手・詰み・王の安全性・打ち歩詰め・千日手は判定しない。
- 通常将棋では敵陣3段に関わる移動で成りを選択できる。行き所のない段に進む場合は、成れば反則にならない。駒打ちでは成れない。
- 成りはブラウザ標準の `window.confirm()` で選ぶ。OKで成り、キャンセルで不成になる。
- 「待った」は成りも含めて一手全体を戻す。
- 移動先表示、盤の反転、初期配置へのリセットに対応。

```sh
make -C apps/shogi build
make -C apps/shogi test
```

設計方針は [DESIGN.md](./DESIGN.md) を参照。

実装は `src/` の TypeScript に置き、ブラウザ用の成果物はビルドで `dist/` に生成する。
公開パスは `/apps/shogi/` とする。バックエンドやデータベースは導入しない。

`src/game.ts` はUIから独立した共通の移動・多段移動・履歴処理、`src/main.ts` は画面操作を担当する。
`src/games/` に、ゲームごとの駒種・初期配置・成り条件を定義する。
対局状態はページ内で保持し、再読み込みすると初期配置に戻る。

通常将棋の二歩・行き所のない駒の条件は [日本将棋連盟の対局規則](https://www.shogi.or.jp/match/taikyoku_rules/) を参照した。同じ側の不成の歩が同じ筋に2枚あれば二歩。歩・香は最奥段、桂は最奥2段に不成で置くと反則となる。

## 中将棋

`/apps/shogi/?game=chu` で直接開ける。

- 12×12盤、各46枚、初期21種類の駒と全成り駒を実装。
- 持ち駒・駒打ちはなく、捕獲した駒は除外する。
- 獅子は隣接マスへ1〜2段移動、または周囲2マスの外周へ跳躍する。1段目で終える場合は「ここで手を終了」を押す。
- 居食いは捕獲後に出発マスへ戻る操作、じっとは空きマスへ出て戻る操作で行う。
- 角鷹は正面、飛鷲は選んだ前方斜めの線で同様の移動を行う。
- 先獅子・後獅子を実装。獅子以外で獅子を取られた直後に、足のある相手の獅子を捕獲すると反則負け。一手間を置くと制限が消える。
- 日本中将棋連盟の補足規則を採用し、隣接する獅子同士の捕獲と付け喰いを例外とする。歩兵・仲人は付け喰いの例外にならない。麒麟が獅子を取りながら成った場合も先獅子が成立する。
- 候補表示はそのまま。成りを含む一手の完了後に判定し、違反理由を表示する。待ったは手全体と反則負けを取り消す。
- 足は手の開始盤面の利きで判断し、捕獲側の出発位置を空けたときのかげ足も含む。利きの判定には先獅子などの制限を適用しない。
- 足のある獅子を獅子で捕獲する制限も実装。手の開始位置から距離1の場合と、歩兵・仲人以外を先に捕獲する付け喰いは許可する。途中で隣接するだけでは距離1の例外にならない。
- 敵陣4段への進入、敵陣に関わる捕獲で成りを選べる。歩兵は最奥段でも成れる。成りは一度だけ。
- 王将と太子をすべて失うと負け。決着は成りを含む一手の完了時に判定する。裸王・千日手・詰みは判定しない。
- 二段移動と成りも1トランザクションにまとめ、待ったで手の開始時点に戻す。
- 狭い画面では盤を横にスクロールできる。

配置・駒の動き・成りは [Chu shogi のルール](https://en.wikipedia.org/wiki/Chu_shogi) と [German Chu Shogi Association の駒一覧](https://www.chushogi.de/rules/chu_rules_pieces.htm) を参照した。決着や禁じ手の扱いは本アプリの設計方針に従う。
先獅子の条件と例外は [日本中将棋連盟の補足規則](https://www.chushogi-renmei.com/kouza/rule_hosoku2004.htm) と [基本規則](https://www.chushogi-renmei.com/kouza/rule.htm) を参照した。

## 大将棋

`/apps/shogi/?game=dai` で直接開ける。

- 15×15盤、各65枚、初期29種類の駒と全成り駒を実装。
- 中将棋の21種類と成り駒の移動定義を再利用し、石将・鉄将・桂馬・嗔猪・猫刃・悪狼・猛牛・飛龍を追加。追加8種類は金将に成る。
- 猛牛・飛龍は1〜2マスの直線移動で、途中の駒を飛び越せない。
- 持ち駒・駒打ちはなく、捕獲した駒は除外する。
- 獅子・角鷹・飛鷲の二段移動、居食い、じっとに対応。獅子の交換規則は適用しない。
- 敵陣5段への進入、敵陣に関わる捕獲で任意に成れる。不成のまま敵陣内を取らずに動く場合は成れない。成りは一度だけ。
- 最奥段での追加の成りの機会は設けない。動けなくなる駒を不成で置いても反則負けにはしない。
- 王将と太子をすべて失うと負け。二段移動・捕獲・成りを含む手全体を「待った」で取り消せる。
- 狭い画面では盤を横にスクロールできる。千日手・裸王・詰み・動ける駒がない場合の決着は判定しない。

配置は [Dai shogi の配置図](https://en.wikipedia.org/wiki/Dai_shogi#Setup)、移動と成り・獅子の扱いは [Dr Eric Silverman の大将棋解説](https://drericsilverman.com/2020/04/13/dai-shogi-part-i-how-to-play/) と [駒の移動一覧](https://drericsilverman.com/wp-content/uploads/2020/04/dai-shogi-reference-2-kanji.pdf) を参照した。最奥段の追加の成りについては、例外を設けない方式を採用した。

## 大局将棋

`/apps/shogi/?game=taikyoku` で直接開ける。

- 36×36盤、各402枚、初期209種類。初期配置と301種類の移動・成り先のデータを大局将棋専用に持つ。
- 同じ名前でも他の将棋とは動きが異なる。王将は8方向へ1〜2マスの通常移動で、跳躍ではない。
- 持ち駒・駒打ちはない。王将と太子をすべて失うと負け。敵陣11段に関わる移動で任意に成れる。成りは一度だけで、不成による行き所のない駒も許可する。
- 鉤行・天狗・摩羯・孔雀などの折れ曲がる移動は、曲がる位置を選んでから次段へ進む。曲がる位置で捕獲した場合はそこで終了する。
- 跳躍後に走る駒は、跳躍先を選んでから同方向へ進む。途中の跳躍先で捕獲した場合はそこで終了する。
- 奔鷲は直接跳躍、居食い・じっと、同方向の3段捕獲（前斜めは4段捕獲）と、その後の走り移動に対応。捕獲列の途中終了は許可しない。進めなくなった場合は「待った」で戻る。
- 通過捕獲する大将などは、指定方向の格下の駒を敵味方ともに取る。同格以上の駒の通過・捕獲は許可しない。
- 教王などは途中の駒を最大3枚まで取らずに飛び越せる。距離3マスという意味ではない。
- 駒の移動・途中捕獲・成りは共通のトランザクションで扱い、「待った」で一手全体を戻す。共通エンジンの型や同じ着地点の効果の検査は拡張していない。
- 盤は縦横にスクロールでき、段の座標表示は36段まで対応。獅子の捕獲制限・千日手・裸王・詰みは判定しない。

駒データと配置は [taikyoku-shogi の公開実装](https://github.com/taikyoku-shogi/taikyoku-shogi.github.io/tree/1dc33afd5b8a018296649845819718031b203fc1) の `pieces.csv`・`initial.tsfen` を参照し、同リポジトリのパーサーで移動を展開したデータを `src/games/taikyoku-data.ts` に収録した。MITライセンスの表示は同ファイル先頭に含め、ビルド後のJavaScriptにも保持する。外部エンジンや追加パッケージは実行時に使わない。
資料間の違いがあるため、成りは本アプリの合意に従い敵陣11段での任意選択とした。奔鷲の連続捕獲は既存のシーケンスで定義する。採用した表現方法は [TAIKYOKU.md](./TAIKYOKU.md) を参照。
