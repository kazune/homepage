# 将棋

通常の将棋と変則将棋の駒を、共通の移動規則で扱う静的ブラウザアプリ。
同じ画面で2人が交互に操作する。画面上部で通常将棋（9×9）と中将棋（12×12）を切り替えられる。

- 持ち駒・駒打ちなし。捕獲した駒は除外する。
- 王手・詰み・王の安全性・千日手などの禁じ手判定なし。
- 通常将棋では敵陣3段に関わる移動で任意の成りを選択できる。行き場のない駒も許可する。
- 「待った」は成りの選択中も含めて一手全体を戻す。
- 移動先表示、盤の反転、初期配置へのリセットに対応。

```sh
make -C apps/shogi build
make -C apps/shogi test
```

設計方針は [DESIGN.md](./DESIGN.md) を参照。

実装は `src/` の TypeScript に置き、ブラウザ用の成果物はビルドで `dist/` に生成する。
公開パスは `/apps/shogi/` とする。バックエンドやデータベースは導入しない。

`src/game.ts` はUIから独立した共通の移動・多段移動・履歴処理、`src/main.ts` は画面操作を担当する。
`src/games/shogi.ts` と `src/games/chu-shogi.ts` に、駒種・初期配置・成り条件を定義する。
対局状態はページ内で保持し、再読み込みすると初期配置に戻る。

## 中将棋

`/apps/shogi/?game=chu` で直接開ける。

- 12×12盤、各46枚、初期21種類の駒と全成り駒を実装。
- 獅子は隣接マスへ1〜2段移動、または周囲2マスの外周へ跳躍する。1段目で終える場合は「ここで手を終了」を押す。
- 居食いは捕獲後に出発マスへ戻る操作、じっとは空きマスへ出て戻る操作で行う。
- 角鷹は正面、飛鷲は選んだ前方斜めの線で同様の移動を行う。
- 先獅子・後獅子を実装。獅子以外で獅子を取られた直後に、足のある相手の獅子を捕獲すると反則負け。一手間を置くと制限が消える。
- 日本中将棋連盟の補足規則を採用し、隣接する獅子同士の捕獲と付け喰いを例外とする。歩兵・仲人は付け喰いの例外にならない。麒麟が獅子を取りながら成った場合も先獅子が成立する。
- 候補表示はそのまま。成りを含む一手の完了後に判定し、違反理由を表示する。待ったは手全体と反則負けを取り消す。
- 足は手の開始盤面の利きで判断し、捕獲側の出発位置を空けたときのかげ足も含む。利きの判定には先獅子などの制限を適用しない。
- 先獅子と関係のない、足のある獅子同士の捕獲制限は実装しない。
- 敵陣4段への進入、敵陣に関わる捕獲で成りを選べる。歩兵は最奥段でも成れる。成りは一度だけ。
- 王将と太子をすべて失うと負け。決着は成りを含む一手の完了時に判定する。裸王・千日手・詰みは判定しない。
- 二段移動と成りも1トランザクションにまとめ、待ったで手の開始時点に戻す。
- 狭い画面では盤を横にスクロールできる。

配置・駒の動き・成りは [Chu shogi のルール](https://en.wikipedia.org/wiki/Chu_shogi) と [German Chu Shogi Association の駒一覧](https://www.chushogi.de/rules/chu_rules_pieces.htm) を参照した。決着や禁じ手の扱いは本アプリの設計方針に従う。
先獅子の条件と例外は [日本中将棋連盟の補足規則](https://www.chushogi-renmei.com/kouza/rule_hosoku2004.htm) と [基本規則](https://www.chushogi-renmei.com/kouza/rule.htm) を参照した。
