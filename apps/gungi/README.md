# 軍儀

商品版「HUNTER×HUNTER 軍儀」の上級ルールを基準に、同じ画面で2人が遊べる非公式の静的ブラウザアプリ。
公開パスは `/apps/gungi/`。入門・初級・中級の切り替えは設けない。

## 操作

- 初期配置は帥から始め、自陣3行へ交互に配置する。最大3段まで重ねられる。
- 「済み」で手駒を残して配置を終了できる。先手の宣言後は後手だけが配置を続け、後手の宣言で先手から対局を開始する。
- 盤上の最上段の駒、または手駒を選び、緑色の移動・配置候補を押す。
- 同じ移動先に複数の操作があるときは「取る」「ツケ」「ツケ＋寝返り」を選ぶ。
- 下段の駒は盤上の小さい表示と、マス選択後の説明で確認できる。
- 14種類の駒について、1〜3段の動きを図で確認できる。
- 「待った」は「本当に待ったをしますか？」で確認し、直前の配置・済み宣言・一手・投了を戻す。キャンセル時は対局と選択を維持する。
- 盤の反転、初期状態へのリセット、投了に対応。

帥の捕獲と投了で決着する。王手・詰み・千日手の自動判定は行わないため、必要な場合は対局者同士で判断する。
先手後手は対局者同士で決める。通信・AI対戦・保存はなく、再読み込みで初期状態に戻る。
採用した規則と参照資料は [rules.md](./rules.md) に記載。

## ビルド・検証

リポジトリ共通のNode.js・pnpm・TypeScriptを使用する。アプリ独自の依存パッケージはない。

```sh
make -C apps/gungi build
make -C apps/gungi test
```

ルートの `make dist` が `app.json` を検出し、`dist/apps/gungi/` への集約とアプリ一覧への登録を行う。

## 実装

- `src/pieces.ts`：駒の種類、枚数、段数別の移動範囲と通過マス。
- `src/game.ts`：軍儀専用の盤面・自由配置・操作候補・捕獲・寝返り・決着・履歴。
- `src/main.ts`：盤、手駒、操作選択、移動範囲図、確認ダイアログ。

盤面は各マスの駒を下段から並べた配列で持つ。捕獲した駒は除外し、手駒には戻さない。
履歴は一手前の状態を保存し、段の順番・手駒・除外駒・手番・配置段階・決着をまとめて戻す。
将棋アプリのエンジンとは独立している。`dist/` と `tests/build/` は生成物として扱う。
